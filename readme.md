### 🛒 Sistema de Gerenciamento de Produto - C#

## 📌 Descrição
Este projeto é um sistema simples de console desenvolvido em C# que permite:

- Registrar um produto com nome, preço e quantidade em estoque.

- Aplicar e remover descontos no valor do produto.

- Visualizar informações detalhadas do produto com ou sem desconto.

- Calcular o valor total em estoque.

- É ideal para praticar construtores, encapsulamento, formatação de entrada numérica e orientação a objetos.

## 🚀 Funcionalidades
- ✅ Cadastro de produto com nome, preço e quantidade.

- ✅ Aplicação de desconto percentual no preço.

- ✅ Remoção de desconto, restaurando o preço original.

- ✅ Cálculo do valor total em estoque com base no preço atual.

- ✅ Suporte a vírgula ou ponto como separador decimal.

🧱 Execução do sistema em si (Ex.)

```bash
Digite o nome do produto: Notebook
Digite o preço do produto: 2500,00
Digite a quantidade em estoque: 10

--- Menu ---
1 - Mostrar informações do produto
2 - Aplicar desconto
3 - Remover desconto
4 - Sair

Digite o percentual de desconto: 10
Desconto aplicado! Novo preço: R$2250,00
```


## 📚 Conceitos Aplicados
- Programação Orientada a Objetos (POO)

- Construtores

- Encapsulamento

- Conversão e formatação numérica com CultureInfo

- Estrutura condicional e laços de repetição

# 🧪 Como executar
Clone o repositório:

ex:
git clone https://github.com/Devmoises79/SystemProdutos

Compile o projeto (caso esteja usando .NET CLI):

```bash
dotnet build
dotnet run
```
Ou, abra o projeto diretamente no Visual Studio ou Visual Studio Code com extensão C# instalada.
